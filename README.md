# Finanzas App 💰

Proyecto personal desarrollado con **Angular**, utilizando **TailwindCSS** y el plugin **DaisyUI** para el diseño frontend.  
La aplicación busca ofrecer una interfaz simple y moderna para gestionar las finanzas personales, con un enfoque en control de gastos, ganancias y cuentas.

---

## 🚀 Características principales
- **Tabla de movimientos**: muestra fecha, gastos, ganancias y el total (ganancias - gastos).
- **Registro de movimientos**: página dedicada para agregar y visualizar transacciones.
- **Gestión de cuentas**: pantalla donde el usuario puede ver el dinero total y el saldo en cada cuenta (bancaria, bolsillo, ahorros).
- **Diseño responsivo**: interfaz moderna y adaptable gracias a TailwindCSS y DaisyUI.

---

## 🎯 Objetivo del proyecto
Este proyecto forma parte de mi **portafolio personal** y tiene como propósito:
- Practicar y demostrar habilidades en **Angular** y librerías modernas de CSS.
- Explorar el diseño de interfaces enfocadas en **usabilidad y control financiero**.
- Servir como base para futuras mejoras, como integración con APIs y almacenamiento en bases de datos.
